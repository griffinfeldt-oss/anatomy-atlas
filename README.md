# Open Anatomy Atlas

A labelled 3D human body you can turn, zoom into and quiz yourself on. Works on iPad, phones and computers.

**Open it:** https://griffinfeldt-oss.github.io/anatomy-atlas/

- Drag with one finger to turn, pinch to zoom, drag with two fingers to move, double-tap to zoom into a spot.
- Slide a body system toward "clear" to see what is inside it.
- Labels: Main / All. "Test myself" hides the names until you tap them.
